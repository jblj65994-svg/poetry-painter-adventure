# 《诗词小画家：诗友奇遇记》低龄互动试玩版

这是面向 4–6 岁儿童的手机优先浏览器原型，后续可迁移为微信小游戏。内容依据已获授权的《漫画古诗词》角色进行 Q 版延展，当前包含 4 个诗境、12 个连续小游戏和 4 张通关诗卷。

## V15 体验

- **一听就会玩**：每关由温柔老师先读出问题，画面中只出现一个会动的目标；孩子只需点一下，或把一个物件拖到另一个物件上。
- **直接操作主画面**：互动发生在完整插画中，不再使用下面的小卡片、文字选项、黄线、虚线圈或抽象图形。
- **真实物件反馈**：亭子、小船、白鹤、雪云、梅枝、花瓣篮、堆肥箱、水壶、花盆等均使用透明 PNG 物件，并在点击后演出对应动作。
- **QQ 农场式成长**：收集落花、制作花肥、喂饱土地、浇水、发芽、长叶、开花形成一条清楚的成长链。
- **真实雪梅表现**：白雪使用雪云、雪晶和雪堆；梅香只用很淡的暖色空气和花粉表现，不再画夸张香气线。
- **逐级陪玩**：约 5 秒没有操作时，目标会做动作提示；随后出现小手完整演示。孩子仍没有操作时，角色会陪着完成。
- **统一语音通道**：宝贝老师、小黑、唐韵和小夫子使用不同声线。跳过、继续、切关或退出时会立刻停止上一段语音，避免重叠。
- **前后台恢复**：动画中切到后台再回来会重置本关；剧情中切后台则回到当前剧情，不会在遮罩后偷播题目。
- **断点续玩**：地图按 12 个任务保存进度，重新进入未完成世界时从下一题继续。

## 四个诗境

| 诗境 | 古诗 | 三个玩法 |
|---|---|---|
| 会变样子的山 | 《题西林壁》 | 送小黑去亭子、点小船看远景、点白鹤飞出群山 |
| 谁更厉害呢 | 《雪梅》 | 点雪云落雪、点梅枝闻香、把白雪送给梅枝 |
| 落花的新旅行 | 《己亥杂诗·其五》 | 花瓣进堆肥箱、给土地施肥、一键浇水看新花长大 |
| 亲手试一试 | 《冬夜读书示子聿》 | 点图画书找办法、把种子放进花盆、浇水等待发芽 |

## 声音资源

V15 正式音频共 80 段：

- 47 段温柔提问、两级提示和旁白鼓励；
- 3 段“种子实验”开场角色对白；
- 30 段角色成功反馈、短剧情旁白和中间反馈。

所有新题目和反馈均映射到本地 MP3。若 WebView 阻止首次自动播放，老师头像会提示“点一下听题”，点击后从当前问题重新朗读。

## 本地试玩

在项目根目录运行：

```powershell
node work/serve-prototype.mjs outputs/poetry-game-prototype 8788
```

然后打开 `http://127.0.0.1:8788/index.html?v=15`。

## 微信小游戏迁移

浏览器版用于儿童试玩与流程定稿。迁移时保留关卡数据、音频映射和状态机，将 DOM/CSS 动画改为 Canvas 或小游戏组件，并把音频预加载、触摸命中区和前后台恢复逻辑接入微信小游戏 API。详见《微信小游戏迁移说明.md》。
